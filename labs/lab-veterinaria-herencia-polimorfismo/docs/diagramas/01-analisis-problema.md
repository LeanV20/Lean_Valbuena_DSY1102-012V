# Análisis del Problema – Veterinaria
## Descripción del dominio
Una veterinaria necesita un sistema para registrar y gestionar 
los animales que atiende. Los animales se dividen en dos grupos: 
mascotas (perros y gatos) y animales salvajes (tigres y leones).
## Requerimientos del sistema
1. El sistema debe registrar la información común de todos los 
   animales: nombre, edad, peso y motivo de consulta.
2. El sistema debe diferenciar entre mascotas y animales salvajes.
3. Cada tipo de animal puede tener comportamientos distintos 
   que el sistema debe poder representar.
4. El sistema debe permitir consultar los datos de cualquier 
   animal sin importar su tipo.
